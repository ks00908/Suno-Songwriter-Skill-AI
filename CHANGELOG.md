# Changelog

## 1.0.0 (October 2026)
First public release.
- Style prompt + tagged lyrics + Exclude styles + title + suggested settings output
- Vibe, brief and own-lyrics modes; any language, with Polish-specific guidance
- Franchise fan songs with lore lookup on primary wikis (~35 franchises listed)
- Call-and-response / cadence formatting (voice tag per turn, no section tags)
- Genre writing rules: rap, metal, EDM, ballads, shanties, spoken word
- Suno v6 family support: models, Weirdness / Style Influence / Variety / Max Mode, editing tools with plan caveats and free fallbacks
- Freshness check against Suno model changes
