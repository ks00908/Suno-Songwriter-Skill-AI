# Primary Lore Sources by Franchise

Use these to check lore before writing fan songs. Search with the wiki name plus the topic (e.g. "Memory Alpha Klingon opera"), then fetch the article from the search results. Many communities have left Fandom for independent wikis; prefer the independent one when both exist, since it's usually better maintained. If a URL here stops working, search "<franchise> wiki" and pick the most active, best-sourced result.

## How to search and verify
1. `<wiki name> <topic>` - e.g. "Halopedia ODST", "Lexicanum Cadian Shock Troops", "UESP Nord songs".
2. Fetch the article, check the infobox for era/dates and affiliations.
3. For culture songs, also fetch pages on the culture's music, rituals, language or sayings.
4. Prefer facts the wiki attributes to a primary source (game, episode, book). Mark anything labelled speculation, fanon, or "unconfirmed" as uncertain.
